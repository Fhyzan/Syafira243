03 · Internship · This Semester

Featured experience

libnis — Library Analytics App

Library of Madrasah Mu'allimaat Muhammadiyah Yogyakarta · Praktik Magang, part of a lecturer's community service program

I built libnis to help the librarians understand how students use the library. I developed the backend API with FastAPI and the desktop interface with Electron and React, working directly with the librarians and my supervising lecturer.

PythonFastAPIElectronReactMySQLSLiMS
  • Borrowing statistics that show which books are most popular among students.
  • Book stock monitoring for the library collection.
  • Tracking of borrowed and returned books.
  • Visitor information that shows which students visit and borrow most often, so the library can give them rewards.

Current status: data is entered manually. I am now developing real-time synchronization with the library's existing SLiMS system.
